# StudyFlow

منصة تعليمية عربية (RTL) تجمع بين المساعد الدراسي الذكي وتنظيم الوقت — React 18 + Vite 6 + TypeScript + Tailwind.

## الوحدات

- لوحة التحكم: إحصائيات حقيقية (وقت الدراسة اليوم، مهام اليوم، أيام الاستمرارية، متوسط الاختبارات) ورسم أسبوعي لدقائق التركيز.
- المساعد الذكي: محادثة مع أي خدمة متوافقة مع OpenAI، مع خيار ضمّان ملخصات ملفاتك في السياق.
- مكتبة الملفات: رفع ملفات PDF (تُحفظ في IndexedDB داخل متصفحك)، فتحها، وتلخيصها بالذكاء الاصطناعي (pdf.js مدمج).
- الملخصات والشروحات: إنشاء من نص أو من ملف، وحفظها للمراجعة.
- الاختبارات: إنشاء يدوي من بنك الأسئلة أو توليد بالذكاء الاصطناعي، مع تصحيح وسجل نتائج.
- بنك الأسئلة: مستودع أسئلة قابل لإعادة الاستخدام.
- بطاقات المراجعة: رزم بطاقات بوجهين.
- المراجعة الذكية: تكرار متباعد (صعب/جيد/سهل) يجدول البطاقات تلقائيًا.
- الخرائط الذهنية: محرر شجري بسيط بعقد وفروع.
- جدول المذاكرة: أسبوع (يبدأ السبت) مع إضافة/تعديل/حذف المهام وملاحظاتها، وتصدير PDF عبر الطباعة.
- مؤقت التركيز: بومودورو 25/5 و50/10 و90/20 مع تسجيل دقائق التركيز تلقائيًا.

## الخصوصية

كل البيانات تُحفظ في متصفح الزائر (localStorage + IndexedDB). لا يوجد خادم ولا حسابات. مفتاح API يُحفظ محليًا فقط ولا يُرسل إلا لخدمة الذكاء الاصطناعي التي يحددها المستخدم في الإعدادات.

## التطوير

```bash
npm install
npm run dev
npm run build   # الناتج في dist/ — يُنشر كما هو على GitHub Pages
```
