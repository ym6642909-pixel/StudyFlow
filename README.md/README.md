# StudyFlow — مساحة دراستك الذكية

مشروع ويب عربي RTL لتنظيم الوقت والمهام الدراسية وقراءة ملفات PDF ومساعدة الطالب على التلخيص والشرح وإنشاء الاختبارات.

## المميزات الحالية
- لوحة تحكم بإحصائيات المهام ووقت التركيز والملفات.
- إدارة مهام مع التاريخ والوقت والأولوية والمدة والإكمال والحذف.
- مؤقت Pomodoro مع 25 و50 دقيقة واستراحة.
- رفع ملفات PDF واستخراج النصوص باستخدام PDF.js.
- حفظ ملفات PDF ونصوصها محليًا باستخدام IndexedDB.
- مساعد دراسي تجريبي، مع إمكانية ربط API متوافق مع OpenAI.
- إعدادات API محفوظة محليًا في المتصفح.
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- PWA وService Worker للتخزين المؤقت بعد أول زيارة.

## التشغيل
1. فك ضغط `StudyFlow.zip`.
2. افتح المجلد في VS Code.
3. شغّل المشروع عبر خادم محلي، وليس بفتح `index.html` مباشرة:
   - باستخدام إضافة **Live Server** في VS Code: اضغط بزر الفأرة الأيمن على `index.html` ثم Open with Live Server.
   - أو باستخدام Python: `python -m http.server 5500` ثم افتح `http://localhost:5500`.
4. اتصال الإنترنت مطلوب أول مرة لتحميل PDF.js والخطوط من CDN. بعد ذلك، الملفات الأساسية تُخزّن مؤقتًا عبر Service Worker.

## تفعيل الذكاء الاصطناعي
1. افتح الإعدادات داخل الموقع.
2. أدخل Base URL لمزود يدعم واجهة OpenAI Chat Completions، واسم النموذج، ومفتاح API.
3. احفظ الإعدادات ثم استخدم المساعد.

**تنبيه أمني مهم:** هذا الإصدار يرسل الطلب من المتصفح مباشرة ويحفظ المفتاح في LocalStorage، لذلك هو مناسب للتجربة الشخصية فقط. لا تنشر مفتاحك داخل موقع عام. للإنتاج، أنشئ Backend/Serverless Function يحفظ المفتاح في متغيرات بيئة ويتحقق من الطلبات.

## حدود PDF
- يستخرج النص المضمن داخل PDF.
- ملفات PDF الممسوحة ضوئيًا كصور تحتاج OCR؛ لم يتم تفعيل OCR في هذا الإصدار.
- ملفات PDF الكبيرة جدًا قد تستهلك مساحة تخزين المتصفح.

## التخزين والخصوصية
المهام والإعدادات تحفظ محليًا في المتصفح. ملفات PDF ونصوصها تحفظ في IndexedDB. حذف بيانات الموقع من إعدادات المتصفح قد يحذف هذه البيانات. لا يوجد حساب مستخدم أو مزامنة سحابية في هذا الإصدار.

## خارطة تطوير مقترحة
- إضافة حسابات مستخدمين ومزامنة سحابية.
- OCR للمحاضرات المصورة.
- تقويم أسبوعي بالسحب والإفلات.
- تصدير الملخصات إلى PDF وWord.
- Backend آمن لطلبات الذكاء الاصطناعي.
- اختبارات تفاعلية مع حفظ الدرجات وسجل المراجعة.
